# 🛒 E-commerce Website

A modern, responsive e-commerce platform built with **HTML5**, **CSS3**, and **Bootstrap**. Features a professional online store design with product showcase, navigation, and clean user interface.

---

## 📌 Project Description

**Target Audience:** Customers browsing and learning about products online

**Primary Focus:** User experience, responsiveness, and professional presentation

## 🚀 Getting Started

### Prerequisites
- **Modern Web Browser** (Chrome, Firefox, Safari, Edge)
- **Text Editor** (VS Code, Sublime Text, etc.)
- **Local Server** (Live Server, Python's http.server, etc.)

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/kocevblagojcho-cell/ecommerce-project.git
cd ecommerce-project
```

2. **Open with a local server:**
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js Live Server
npx live-server
```

3. **Access in browser:**
Navigate to `http://localhost:8000` or the URL provided by your server.

## 🎯 Customization

### Changing Products
Edit the product data in `js/script.js`:
```javascript
const products = [
  {
    id: 1,
    name: "Product Name",
    price: 29.99,
    image: "images/product.jpg"
  }
];
```

### Color Scheme
Modify CSS variables in `css/style.css`:
```css
:root {
  --primary-color: #007bff;
  --secondary-color: #6c757d;
  --accent-color: #ffc107;
}
```

### Content
Update HTML in `index.html` to change text, images, and structure.
